# Goblin Cartel: MVP и следующие шаги

**Версия:** 0.1  
**Дата:** 2026-04-28

## 1. Цель MVP

MVP должен доказать, что основной цикл игры приятен:

```text
копать блоки → получать ресурсы → найти жилу → построить шахту → собрать доход → купить автоматизацию → копать глубже
```

MVP не должен доказывать всё сразу. Никаких клановых войн, PvP, сезонных боевых пропусков, мультивселенной гоблинов и прочих способов превратить первую версию в управленческий комбайн, который никто не доделает.

## 2. Формат MVP

MVP должен быть доступен как:

1. **Web-версия** для быстрой разработки и тестирования.
2. **Android build через Capacitor** для проверки поведения в Android WebView.
3. **Внутренняя админка** для настройки базовых сущностей и генерации рудников.

Для первой публичной публикации в RuStore можно выпустить ограниченную версию с понятным игровым циклом, без real-money платежей на старте. Если монетизация нужна в первой публикации, её надо проектировать отдельно и заранее под RuStore SDK.

## 3. MVP: что входит

### 3.1. Игровые экраны

| Экран | Содержание | Приоритет |
|---|---|---|
| Рудник | 2D шахта, блоки, гоблины, тапы, ресурсы | P0 |
| Гоблины | список гоблинов, статы, назначение, улучшение | P0 |
| Шахты | построенные шахты, доход, хранилище, сбор | P0 |
| Автоматизация | старший шахтёр, собиратель, вагонетка, бригадир | P0 |
| Производство | базовая плавильня и переработка | P1 |
| Настройки | звук, язык, сброс, версия, политика | P1 |

### 3.2. Рудники

В MVP нужно 3 рудника:

| Рудник | Цель | Особенности |
|---|---|---|
| Старый колодец | обучение | земля, камень, золото, первая жила |
| Медная расщелина | первый ресурсный скачок | медь, твёрдые блоки, сундуки |
| Железный провал | открытие автоматизации | железо, хлам, первые детали |

### 3.3. Размер рудника

Для MVP:

```text
8 колонок × 12-14 слоёв
```

На экране одновременно видно примерно 8×7 блоков. Остальное ниже, камера/viewport двигается по глубине.

### 3.4. Типы блоков

| Блок | Приоритет | Назначение |
|---|---|---|
| Земля | P0 | быстрый блок для обучения |
| Камень | P0 | базовый блок |
| Твёрдый камень | P0 | проверка силы гоблинов |
| Медная руда | P0 | первый промышленный ресурс |
| Железная руда | P0 | ресурс для автоматизации |
| Золото | P0 | валюта и награда |
| Хлам | P1 | детали для механизмов |
| Сундук | P1 | случайные награды |
| Пороховой пузырь | P2 | цепная реакция, можно после MVP |

### 3.5. Гоблины MVP

Минимум 8 гоблинов:

| Имя | Класс | Роль |
|---|---|---|
| Грызз Кривозуб | шахтёр | базовый урон по камню |
| Мык Тупая Кирка | шахтёр | дешёвый рабочий |
| Скрапп Медный Нос | шахтёр | бонус по медной руде |
| Румм Тяжёлая Лапа | шахтёр | медленный, сильный |
| Брикк Молоток | строитель | строит первые шахты |
| Тикк Ровная Доска | строитель | дешевле строит |
| Пип Сухая Книга | собиратель/бухгалтер | авто-сбор с одной шахты |
| Кракк Железная Репа | бригадир | авто-выбор следующего блока |

### 3.6. Шахты MVP

| Шахта | Источник | Производит |
|---|---|---|
| Малая золотая шахта | золотая жила | золото |
| Малая каменоломня | каменный пласт | камень |
| Малая медная шахта | медная жила | медная руда |
| Малая железная шахта | железная жила | железная руда |

### 3.7. Автоматизация MVP

| Автоматизация | Условие открытия | Эффект |
|---|---|---|
| Старший шахтёр | 3 шахтёра | гоблины переходят к следующему блоку без ручного выбора |
| Собиратель | 2 построенные шахты | авто-сбор с одной шахты |
| Вагонетка | первая железная руда | ускоряет сбор и повышает вместимость |
| Бригадир | прохождение 2 рудников | управляет несколькими шахтёрами |
| Буровая стойка | хлам + железо | пассивно бьёт выбранную колонку |
| Шахтный участок | 10 одинаковых шахт | объединяет шахты в один объект |

### 3.8. Переработка MVP

Минимальная плавильня:

```text
Медная руда → Медные слитки
Железная руда → Железные слитки
Хлам → Детали
```

Смысл: показать, что добыча дальше превращается в производство, а не просто складируется как цифровой мусор с амбициями.

## 4. MVP: что не входит

| Система | Почему не входит |
|---|---|
| PvP | слишком рано, разрушает спокойный старт |
| Защита базы | игрок ещё не привязался к активам |
| Клановые войны | нужна экономика и кланы как база |
| Шум / инспекторы | хорошая система, но вводится позже |
| Сезонные события | сначала нужен стабильный core loop |
| Платежи | можно добавить позже после проверки UX |
| Сложные задания | сначала простые цели обучения |
| Реальная multiplayer-синхронизация | не нужна для первого доказательства игры |

## 5. Первый час игры

### 0-5 минут

- Игрок видит вертикальную шахту.
- Получает первого гоблина-шахтёра.
- Ломает первые блоки.
- Использует энергию босса для тапа.
- Получает золото и камень.

Цель: `Разбей 10 блоков`.

### 5-15 минут

- Нанимает второго шахтёра.
- Открывает блоки медной руды.
- Находит первую жилу.
- Знакомится со строителем.

Цель: `Построй первую малую шахту`.

### 15-30 минут

- Шахта производит ресурс по таймеру.
- Игрок вручную собирает доход.
- Открывается экран шахт.
- Появляется лимит хранилища.

Цель: `Собери доход с шахты 3 раза`.

### 30-45 минут

- Появляется собиратель.
- Первый авто-сбор.
- Игрок видит пользу автоматизации.

Цель: `Назначь собирателя на шахту`.

### 45-60 минут

- Игрок открывает железный рудник.
- Получает железо и хлам.
- Открывает вагонетки / бригадира.
- Видит идею укрупнения шахт.

Цель: `Построй 3 шахты и купи первую автоматизацию`.

## 6. Roadmap после MVP

### Этап 1. Core polish

- Улучшить отзывчивость тапа.
- Добавить состояния блоков: целый, трещины, почти сломан, разрушен.
- Ввести базовые звуки.
- Доработать сохранение.
- Настроить офлайн-прогресс.
- Проверить производительность Android WebView.

### Этап 2. Производство

- Плавильни.
- Цепочки ресурсов.
- Рецепты.
- Инструменты для гоблинов.
- Улучшения шахт через переработанные ресурсы.

### Этап 3. Кланы как специализации

- Ржавые Кирки: копание и руда.
- Пороховые Уши: взрывы и ускорение проходки.
- Чёрные Карманы: сбор, сундуки, потери.
- Болтовые Черепа: механизмы и автоматизация.

На этом этапе кланы ещё не политическая система, а понятные специализации.

### Этап 4. Территории

- Карта Подземья.
- Новые зоны добычи.
- Контракты на участки.
- Ресурсные регионы.
- Постепенное подключение конкурентов.

### Этап 5. События

- Золотая лихорадка.
- Великий обвал.
- Пороховой фестиваль.
- Чёрный рынок руды.

### Этап 6. Картельная стратегия

- Шум / Heat meter.
- Инспекторы.
- Клановые отношения.
- Захват территорий.
- Рейды и защита.

## 7. Критерии успеха MVP

MVP считается успешным, если:

1. Игрок понимает, что делать, без длинного туториала.
2. Разрушение блоков приятно само по себе.
3. Первая построенная шахта ощущается как награда.
4. Авто-сбор воспринимается как облегчение, а не как лишняя галочка.
5. Игрок хочет открыть следующий рудник.
6. В web-версии стабильный FPS.
7. Android build не ломает UI, ввод и сохранения.
8. Контент рудников можно менять через конфиг, не лезя в код.

## 8. Основные риски MVP

| Риск | Что делать |
|---|---|
| Тапание утомляет | ограничить через энергию, добавить авто-добычу рано |
| Игрок не понимает ценность шахт | первая жила должна быстро превратиться в постоянный доход |
| Слишком много ресурсов | в MVP оставить 5 ресурсов |
| UI мелкий на телефоне | 8 колонок, крупные блоки, большие кнопки |
| Экономика ломается | сделать симулятор баланса в админке |
| Рудники однообразны | добавить типы блоков, сундуки, гарантированные находки |
| Android WebView тормозит | ограничить частицы, батчить PixiJS-спрайты, тестировать на слабых устройствах |
