# Goblin Cartel: общее описание и концепт игры

**Версия:** 0.1  
**Дата:** 2026-04-28

## 1. Короткий питч

**Goblin Cartel** — это 2D idle/tapper mining game, где игрок управляет гоблинской бандой, копает вертикальные рудники, находит жилы, строит шахты, автоматизирует добычу и постепенно превращает кривой подземный лагерь в промышленный гоблинский картель.

Главная формула:

```text
Копай глубже → находи ресурсы → строй шахты → автоматизируй → объединяй → открывай новые рудники → расширяй картель
```

Игра начинается спокойно: без PvP, без угрозы, что базу “натянут”, без раннего управленческого хаоса. Игрок сначала учится добывать, строить и автоматизировать. Конфликты, кланы, события и территории подключаются позже, когда у игрока уже есть собственность, которую жалко терять. Примитивная человеческая привязанность к пиксельной меди, но работает.

## 2. Жанр

- 2D idle game.
- Tapper / clicker с ограниченной энергией игрока.
- Экономическая игра про производство и автоматизацию.
- Позже: лёгкая стратегия с кланами, событиями и территориями.

## 3. Целевая платформа

Игра проектируется как:

1. **Android-приложение** — основная публикация, первая площадка: RuStore.
2. **Web-версия** — для разработки, тестирования, демо и возможной публичной web-версии.
3. **Админка** — отдельное web-приложение для управления контентом, генерации рудников, баланса и событий.

## 4. Фантазия игрока

Игрок должен чувствовать:

> “Я начинал с одного гоблина и грязного колодца, а теперь у меня рельсы, шахты, плавильни, бригадиры и производство, которое работает, даже когда я ушёл.”

Ключевая эмоция: **ручная рутина постепенно заменяется автоматизацией**.

Это очень важно. Игрок не просто получает “+7% к добыче”. Он избавляется от действий, которые раньше делал сам:

| Было руками | Стало автоматически |
|---|---|
| Тапать блоки | Гоблины и бур бьют сами |
| Выбирать следующий блок | Бригадир назначает цель |
| Собирать доход шахты | Собиратель и вагонетки собирают сами |
| Строить каждую шахту | Строительная бригада завершает типовые стройки |
| Управлять десятками шахт | Шахты объединяются в участки и заводы |

## 5. Основной игровой цикл

```text
1. Игрок открывает рудник.
2. Гоблины долбят блоки породы.
3. Игрок помогает ударами босса, расходуя энергию.
4. Блоки дают ресурсы, сундуки, редкие находки.
5. В руднике находится жила.
6. Гоблин-строитель строит постоянную шахту на жиле.
7. Шахта начинает производить ресурс по таймеру.
8. Игрок собирает доход вручную.
9. Игрок покупает автоматизацию.
10. Несколько шахт объединяются в более крупный объект.
11. Открывается следующий, более сложный рудник.
```

## 6. Сеттинг

Мир игры — подземное гоблинское Подземье: рудники, хламовые тоннели, старые механизмы, пороховые лаборатории, чёрный рынок, вагонетки, ржавые буровые установки и бухгалтеры, от которых даже демоны чувствуют неловкость.

Тон игры:

- мрачноватый, но смешной;
- гоблины жадные, нелепые и полезные;
- мир грязный, деревянно-железный, подземный;
- юмор строится на абсурде производства, жадности и гоблинской некомпетентности;
- без реалистичного криминала, только фэнтезийная “мафия шахтёров”.

## 7. Игровые столпы

### 7.1. Видимый прогресс

Игрок должен видеть, как шахта уходит вниз, как блоки ломаются, как появляются новые жилы, как база превращается в промышленную систему.

### 7.2. Простое действие на старте

Сначала игрок делает очень понятную вещь: ломает блоки. Не выбирает дипломатический курс с кланом “Пороховые Уши”, не защищает базу от рейда, не читает 14 вкладок туториала. Просто камень, гоблин, кирка. Мир иногда умеет быть милосердным.

### 7.3. Автоматизация как награда

Каждая крупная новая система должна убирать часть ручной рутины.

### 7.4. Контент через конфиги

Блоки, рудники, гоблины, ресурсы, шахты, автоматизация, рецепты и события должны задаваться через данные, а не через хардкод.

### 7.5. Расширяемость

MVP должен стать фундаментом для будущих систем:

- кланы;
- территории;
- события;
- рейды;
- чёрный рынок;
- сезонные карты;
- фабрики и производство;
- монетизация и LiveOps.

## 8. Главный экран игры

Главный экран — вертикальный рудник.

Композиция:

```text
Верхняя панель:
- золото
- камень
- руда
- энергия босса
- прогресс глубины

Центр:
- вертикальный рудник 8×N
- видимая часть примерно 8×7 блоков
- гоблины на платформе сверху
- активный блок с HP-bar
- эффекты трещин и разрушения

Низ:
- кнопка “Удар босса”
- прогресс текущего блока
- bottom navigation: Рудник / Гоблины / Шахты / Авто / Производство
```

## 9. Персонажи

Персонажи — это гоблины с классом, кланом, ролью и бонусом. На старте кланы можно не объяснять глубоко, но визуально они уже должны отличаться.

### 9.1. Классы гоблинов

| Класс | Назначение | Когда появляется |
|---|---|---|
| Шахтёр | Бьёт блоки в руднике | сразу |
| Строитель | Строит шахты на найденных жилах | ранняя игра |
| Собиратель | Собирает доход с шахт | ранняя автоматизация |
| Инженер | Улучшает машины, рельсы, буровые | середина MVP |
| Бригадир | Авто-назначение целей и управление сменой | поздняя часть MVP |
| Подрывник | Взрывает блоки, ускоряет проходку, повышает риск | после MVP / ранний expansion |
| Торговец | Обмен ресурсов, чёрный рынок | после MVP |
| Бухгалтер | Снижает потери, автоматизирует сбор, готовит систему “шума” | после MVP или late MVP |

### 9.2. Примеры гоблинов

#### Грызз Кривозуб

- **Класс:** шахтёр.
- **Клан:** Ржавые Кирки.
- **Редкость:** обычный / редкий.
- **Визуал:** каска со свечой, огромная ржавая кирка, один зуб, грязные перчатки.
- **Способность:** `Камнегрыз` — +20% урона по камню.
- **Роль в MVP:** первый понятный рабочий.

#### Бумп Ухо-Порох

- **Класс:** подрывник.
- **Клан:** Пороховые Уши.
- **Редкость:** редкий.
- **Визуал:** обожжённое ухо, бочки с порохом, треснутая каска, слишком счастливое лицо.
- **Способность:** `Нормально бахнет` — крит может взорвать соседний блок.
- **Риск:** шанс мини-обвала.
- **Роль:** вводит риск/награду после базовой шахтной игры.

#### Пип Сухая Книга

- **Класс:** бухгалтер / автоматизатор.
- **Клан:** Чёрные Карманы.
- **Редкость:** редкий.
- **Визуал:** очки, книга долгов больше него, чернильные пятна.
- **Способность:** `Скучный порядок` — авто-сбор с одной шахты, снижение потерь.
- **Роль:** первый персонаж, который показывает ценность автоматизации.

#### Кракк Железная Репа

- **Класс:** бригадир.
- **Клан:** Жирный Трон.
- **Редкость:** эпический.
- **Визуал:** крупный гоблин с дубинкой-указкой и табличкой “РАБОТАТЬ”.
- **Способность:** `Без простоев` — гоблины автоматически переходят к следующему блоку.
- **Роль:** убирает ручной выбор цели.

## 11. Визуальный стиль

Рабочее направление:

> **dirty cartoon dark fantasy industrial UI**

Характеристики:

- 2D;
- крупные формы;
- толстая обводка;
- дерево, камень, медь, железо;
- тёмный фон и тёплые акценты;
- гоблины с выразительными силуэтами;
- UI как будто собран из досок, болтов и плохих решений.

## 12. Минимальные анимации

Не требуется 3D и сложная skeletal-анимация. Достаточно:

| Объект | Анимация |
|---|---|
| Гоблин | idle bounce + 2 кадра удара |
| Блок | трещины при уроне |
| Разрушение | пыль + вылет ресурса |
| Кнопка удара | пульс при полной энергии |
| Вагонетка | простое движение по рельсам |
| Бур | вращение/тряска |
| Жила | вспышка + popup |

## 13. Будущая надстройка Goblin Cartel

Когда шахтное ядро работает, можно подключать более широкий концепт:

1. **Кланы** — специализации и отношения.
2. **Территории** — новые зоны добычи и промышленности.
3. **Шум / Heat** — риск инспекций и конфликтов.
4. **События** — временные рудники, золотая лихорадка, обвалы.
5. **Рейды** — не в начале, а когда игрок понимает ценность шахт.
6. **Чёрный рынок** — обмен, редкие гоблины, контракты.
