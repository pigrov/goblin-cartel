# 0019 Platform Overlay And PixiJS Plan

## Цель

Исправить визуальную модель платформы:

- шахта не должна разъезжаться из-за вставленной между рядами платформы;
- платформа должна быть вторым слоем поверх цельной шахтной сетки;
- спуск должен ощущаться как отдельное событие;
- механизм спуска не должен занимать колонку глубины и налезать на цифры;
- зафиксировать будущий переход визуального слоя шахты на PixiJS.

## Сделано

- `mine-platform-row` удален из потока рядов.
- Платформа переведена в `mine-platform-layer`: абсолютный overlay внутри `.mine-grid`.
- Позиция overlay считается по текущему DOM-ряду шахты и первой/последней каменной колонке.
- Ряды шахты теперь остаются непрерывными: платформа не вставляется между блоками.
- Механизм спуска перенесен к левому краю первой каменной колонки.
- Платформа получила более читаемый вид настила: общая дека, доски, балки, тени и два троса.
- Анимация спуска увеличена до `1450ms` и получила инерцию/мягкий отскок.

## PixiJS План

PixiJS уже подключен в `@goblin-cartel/game-client`, но текущий экран шахты пока работает на React + CSS.

Переход на PixiJS стоит делать отдельной итерацией, когда базовая механика платформы стабилизируется:

1. Оставить `game-core` источником правил добычи, HP, наград, `platformRow`, offline progress.
2. Вынести визуальное состояние шахты в адаптер: блоки, активный ряд, гоблины, эффекты удара, события спуска.
3. Создать Pixi canvas только для игрового поля: поверхность, шахта, платформа, гоблины, частицы.
4. Оставить React для HUD, энергии, модалок, навигации и админских UI.
5. Перенести эффекты ударов, тросы и плавный спуск платформы в Pixi sprites/containers.
6. После стабилизации заменить CSS-камни на Pixi-камни, сохранив текущие React-контролы вокруг сцены.
