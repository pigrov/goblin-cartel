# Итерация 0047: жила после полной очистки рудника

## Цель

Исправить сценарий прохождения рудника: жила не должна быть странным отдельным камнем внутри сетки. Игрок должен полностью расчистить рудник, получить окно с найденной жилой и построить постоянную шахту. Сундук должен выдаваться не сразу за построенную шахту, а как награда за переход в новый рудник.

## Сделано

- Добавлено поле `completionVeinTypeId` у шаблона рудника: жила теперь является наградой за полную очистку рудника.
- Из starter-контента убраны гарантированные `vein`-блоки, поэтому в шахте больше не появляется специальный “камень-жила”.
- Первая шахта временно уменьшена до 10 метров для быстрого тестирования.
- Добавлены `gold_vein_small` и `small_gold_mine`: первая шахта после полной очистки находит золотую жилу и предлагает построить золотую шахту.
- В `game-core` добавлено определение полной очистки рудника и создание `MiningFoundVein` только после уничтожения последнего блока.
- Окно найденной жилы переписано под сценарий “Рудник расчищен”: показывает стоимость строительства, добычу в час и кнопки “Построить” / “Построить позже”.
- Автоматический показ сундука после строительства шахты отключён; сундук открывается только при попытке перейти в следующий рудник.
- Backend и runtime-клиент теперь сортируют `mineTemplates` по `sortOrder`/starter-порядку, чтобы опубликованный контент не начинался с `abandoned_crosscut_02`.
- Runtime-нормализация старого production-контента добавляет новые starter-сущности, убирает legacy guaranteed vein и выставляет 10-метровую тестовую глубину.
- Обновлено описание правила жил в `docs/05_game_systems_economy.md`.
