# Итерация 0099: упрощение карточек найма

## Цель

Сделать карточку найма гоблина более компактной: оставить только роль, картинку, две ключевые характеристики и кнопку найма с ценой в золоте.

## Сделано

- Убран верхний информационный блок экрана гоблинов:
  - заголовок `Гоблины`;
  - строка уровня хижины и лимита;
  - общий урон;
  - вкладки ролей;
  - сводка по шахтерам, сборщикам, автосбору и бригадирам.
- Контракты найма теперь показывают все доступные типы без отдельного фильтра по вкладкам.
- Карточка контракта теперь содержит:
  - тип гоблина;
  - render-картинку из `renderPool`;
  - две основные характеристики по роли;
  - кнопку `Нанять` с ценой в золоте.
- Визуально карточка дополнительно упрощена:
  - иконка роли в шапке карточки убрана;
  - общий фон секции контрактов убран;
  - цветной градиентный фон карточки убран, остается только asset base из `hireCardSkin`;
  - border карточки найма убран;
  - disabled/locked стили карточки убраны, состояние блокировки остается только на кнопке;
  - формат карточки зафиксирован как `3:4`, без `min-height`, который раньше растягивал карточку;
  - сетка контрактов оставлена с компактным `gap: 2px`, секция гоблинов поджата до `padding: 6px`;
  - заголовок роли в карточке переведен на общую переменную `--gc-heading`, uppercase и плотную пиксельную тень `--gc-heading-shadow`;
  - у кнопок отключен стандартный синий mobile tap-highlight;
  - экран `Гоблины` получил настраиваемый фон-паттерн `Фон экрана Гоблины` через админку;
  - добавлена настраиваемая через админку плашка `Плашка заголовка` для блока `НАЙМ ГОБЛИНОВ`, ширина в игре `2/3` экрана;
  - заголовок личных гоблинов заменен на ту же плашку с текстом `ВАШИ ГОБЛИНЫ X/Y`;
  - личные гоблины получили отдельную настраиваемую подложку и стрелку апгрейда через блок админки `UI личных гоблинов`;
  - карточка личного гоблина теперь показывает только рендер, текущий уровень слева сверху и стрелку апгрейда справа сверху при доступном улучшении;
  - глобальный основной шрифт темы теперь подключает локальный `Russo One` через `@font-face`;
  - локальные `font-family` перебивки в CSS игры и админки удалены, UI наследует общий шрифтовой стек;
  - глобальный `font-weight` задан как `500`, явные `font-weight` удалены из CSS игры и админки;
  - зоны шаблона 450x600 закреплены процентами:
    - шапка: `22-70px`, около `8%` высоты;
    - фото: `76-330px`, около `42.3%` высоты;
    - параметры: `337-438px`, около `16.8%` высоты;
    - кнопка: `448-568px`, около `20%` высоты;
  - характеристики показываются двумя строками: слева полное название в фиксированной колонке с ellipsis при нехватке места, справа иконка плюс значение с выравниванием по левому краю.
- Первый случайный контракт снова бесплатный, следующие наймы используют gold-only стоимость архетипа с учетом множителя Хижины.
- Starter content переведен на gold-only hire cost:
  - шахтер: `220` золота;
  - сборщик: `900` золота;
  - бригадир: `2400` золота.
- Content validation теперь запрещает non-gold ресурсы в `goblinGeneration.archetypes.*.hireCost`.
- Starter render pool привязан к asset pack:
  - `goblin_hire_miner_v1`;
  - `goblin_hire_builder_v1`;
  - `goblin_hire_foreman_v1`.
- В админке картинки гоблинов для найма редактируются в `Content -> Генерация -> Архетип -> Пул рендеров`.
  Блок `UI карточки найма` управляет только рамками, кнопками, плашками цены и иконками.
- Локальный baseline-контент пересоздан как версия `0.1.7` через `content:reset-baseline`.
