# 0031 Pixi Effects Module Near Break

## Цель

Разгрузить `MinePixiScene.tsx` после роста Pixi-эффектов и добавить визуальное состояние камня перед разрушением, чтобы игрок видел, что блок уже близок к последнему удару.

## Сделано

- Вынесены типы и отрисовка hit effects из `MinePixiScene.tsx` в `minePixiEffects.ts`.
- Удалены дубли локальных helper-функций эффектов из Pixi-сцены.
- Добавлен визуальный индикатор `near break`: усиленный контур, дополнительные трещины и малые осколки при HP блока `<= 22%`.
- Вынесены чистые расчеты HP-процента и intensity в `minePixiBlockVisualState.ts`.
- Добавлен unit-тест на расчет состояния `near break`.

## Проверки

- `pnpm --filter @goblin-cartel/game-client typecheck`
- `pnpm --filter @goblin-cartel/game-client test`
- `pnpm lint`
- Визуальная проверка Pixi canvas на мобильном viewport: после удара босса блок с `2/20 HP` получает near-break подсветку.

## Открытые вопросы

- В следующей итерации стоит продолжить выносить Pixi-сцену на модули по зонам ответственности: блоки/платформа/гоблины/input.
- Для “последнего удара” офлайн-добычи позже нужен отдельный визуальный сценарий, чтобы near-break состояние не конфликтовало с queued final hit.
