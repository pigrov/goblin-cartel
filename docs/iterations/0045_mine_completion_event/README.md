# Итерация 0045: событие освоения рудника

## Цель

Сделать переход к следующему руднику более игровым: после постройки постоянной шахты из жилы текущего рудника игрок должен увидеть отдельное событие “Рудник освоен” со сводкой и выбором, идти дальше сейчас или остаться.

## Сделано

- Добавлена модалка “Рудник освоен” после выполнения условия перехода к следующему руднику.
- В модалке показывается текущий рудник, закрепленная жила, построенная постоянная шахта и открытый следующий маршрут.
- Из модалки можно сразу перейти в следующий рудник или остаться в текущем меню шахт.
- Показ события сохраняется в локальном прогрессе, чтобы модалка не всплывала повторно после закрытия или перезахода.
- Сброс прогресса очищает состояние показанных событий освоения.
- В `mineProgressionClientState` добавлены функции для одноразового показа события и unit-тесты.
