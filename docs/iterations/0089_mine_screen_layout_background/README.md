# Iteration 0089: Mine Screen Layout Background

Дата: 2026-05-04

## Контекст

После фикса Android CORS экран рудника снова работает в установленном приложении. Следующая правка направлена на компоновку самого рудника: боковые действия должны быть собраны в одной колонке, а игровая область должна занимать больше полезной ширины.

## Сделано

- Кнопки рудника `Подъемник`, `Вышка` и `Прогресс` перенесены в левую вертикальную колонку под кнопками энергии, карт и умения босса.
- Убраны метки глубины на шахте и резерв ширины под них в Pixi layout.
- Убрана поверхностная надпись `DEPTH` и номер глубины.
- Добавлен фон рудника на всю область экрана, включая пространство между шахтой и нижним меню.
- Добавлена более выраженная пещерная подложка внутри Pixi-сцены: темные боковые зоны, слои породы и мелкие каменные акценты.
- Тест layout обновлен так, чтобы фиксировать отсутствие отдельной ширины под depth markers.

## Проверки

- `pnpm --filter @goblin-cartel/game-client typecheck`
- `pnpm --filter @goblin-cartel/game-client test`
- `pnpm --filter @goblin-cartel/game-client build`
- `pnpm lint`
- `pnpm encoding:check`
- Локальная визуальная проверка на мобильном viewport `430x860` с прокси на продовый контент.

## Замечания

- Состояние модалок рудника осталось внутри `MineScreen`, чтобы не разносить его по общему контроллеру.
- Старый модуль depth markers пока не удален полностью, но в рендер-проходе слой очищается и не отрисовывается. Полное удаление можно сделать отдельной чисткой, если не понадобится вернуть метки в другом формате.
