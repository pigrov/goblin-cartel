# 0021 Pixi Mine Scene

## Цель

Начать переход игровой шахты с DOM/CSS-разметки на PixiJS, не меняя правила добычи и сохранения.

## Сделано

- Добавлен `MinePixiScene` для canvas-отрисовки поверхности, шахты, глубинных меток, платформы и гоблинов.
- Платформа теперь рисуется поверх шахты вторым слоем и привязана к текущему ряду шахты.
- Босс по-прежнему бьет только открытые верхние блоки, но клики теперь приходят из Pixi-сцены.
- Ручное переставление гоблинов перенесено в Pixi: гоблина можно зажать и отпустить над доступной ячейкой платформы.
- Правила добычи, офлайн-прогресс, энергия босса, найм гоблинов и сохранение остались в `game-core` и `App`.
- Старый DOM-рендер шахты удален из `App`, чтобы дальше развивать один визуальный слой.
- Добавлены стили контейнера canvas для скролла всей игровой области.

## Важные решения

- PixiJS используется только как визуальный и input-слой. Бизнес-логика не дублируется в компоненте сцены.
- Сцена получает готовые `session`, `exposedCellKeys`, `platformCellKeys`, `goblins` и события `onBlockHit`/`onPlaceGoblin`.
- Canvas имеет полную высоту контента, поэтому скролл остается у игровой области, включая поверхность и шахту.
