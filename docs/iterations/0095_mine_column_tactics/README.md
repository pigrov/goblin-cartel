# Итерация 0095: тактические подсказки колонок рудника

## Цель

Дать игроку первый повод осмысленно переставлять шахтеров между колонками: экран рудника должен показывать, где текущий гоблин подходит к блоку хорошо, а где другой шахтер из команды был бы эффективнее.

## Сделано

- Добавлен клиентский расчет `createMineColumnTacticHints`.
- Для каждой живой клетки под платформой рассчитывается:
  - текущий урон гоблина в колонке;
  - лучший возможный урон среди нанятых шахтеров;
  - лучший шахтер для тегов текущего блока;
  - наличие бонуса по тегам блока;
  - состояние колонки: пустая, слабая, хорошая или лучшая.
- Pixi-рудник теперь рисует компактные подсказки прямо на верхних блоках:
  - зеленый - стоит лучший шахтер;
  - желтый - текущий шахтер почти подходит;
  - красный - колонку выгодно переставить;
  - синий - колонка пустая, но есть подходящий шахтер;
  - золотая точка - лучший шахтер получает бонус от тегов блока.
- Добавлены unit-тесты на расчет пустой, слабой и оптимальной колонки.

## Проверки

- `pnpm --filter @goblin-cartel/game-client test -- mineColumnTactics`
- `pnpm --filter @goblin-cartel/game-client typecheck`
