# 0068 Hut Upgrade Progression

## Цель

Сделать саму Хижину частью прогрессии: ограничивать количество нанятых гоблинов, открывать роли по уровням, давать бонусы к найму и прокачке, а также привязать апгрейды Хижины к прогрессу рудников и построенных шахт.

## Сделано

- В content-схему добавлен top-level блок `goblinHut` с уровнями Хижины.
- Уровень Хижины теперь задает:
  - лимит нанятых гоблинов;
  - открытые роли гоблинов;
  - множитель стоимости найма;
  - множитель стоимости прокачки;
  - стоимость апгрейда;
  - условия апгрейда по рудникам и построенным шахтам.
- В game-core добавлена логика:
  - нормализация уровня Хижины в roster;
  - проверка лимита найма;
  - блокировка найма закрытых ролей;
  - расчет скидок найма и прокачки;
  - апгрейд Хижины с расходом ресурсов и проверкой прогресса.
- Экран `Хижина` показывает текущий уровень, лимит, открытые роли, бонусы и следующий апгрейд.
- Карточки гоблинов теперь учитывают лимит Хижины, закрытые роли и скидки.
- В админке добавлена вкладка `Хижина` для редактирования уровней, лимитов, ролей, стоимости и условий прогресса.
- Backend content-store и entity-save поддерживают сохранение `goblinHut` как отдельной content entity.
