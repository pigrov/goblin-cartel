# 0024 Pixi Addressable Cells

## Цель

Уменьшить лишнюю работу Pixi-сцены при ударах, автодобыче и прокрутке: вместо очистки слоя шахты и полной пересборки видимого диапазона обновлять только те клетки, метки и эффекты, чье визуальное состояние реально изменилось.

## Сделано

- Добавлен render-state слой для Pixi:
  - `createMinePixiBlockRenderSignature` формирует сигнатуру визуального состояния клетки;
  - `createMinePixiVisibleCellKeySet` собирает ключи клеток в текущем видимом диапазоне.
- В `MinePixiScene` добавлены реестры уже созданных Pixi-нод:
  - блоки шахты по ключу `row:col`;
  - метки глубины по номеру ряда;
  - эффекты ударов по `effect.id`.
- Слой `mine` больше не очищается целиком при каждом изменении `session.blocks`.
- При изменении HP, разрушении, активности, открытости, типа блока или размера клетки заменяется только конкретная Pixi-нода блока.
- При прокрутке удаляются ноды, ушедшие из visible range, и создаются только ноды новых видимых клеток.
- Метки глубины и эффекты ударов переведены на такую же reconcile-модель.
- Добавлены unit-тесты для сигнатур и набора видимых ключей.

## Важные решения

- Сигнатура включает только параметры, влияющие на внешний вид и интерактивность блока. Это позволяет не пересоздавать Pixi-объект, когда React передал новый объект состояния, но визуально клетка не изменилась.
- События клика на блок остаются на самой Pixi-ноде. Если сигнатура изменилась, нода пересоздается вместе с актуальным обработчиком.
- Платформа пока остается отдельным слоем с полной перерисовкой. Она маленькая и меняется реже, а оптимизация платформы лучше делать вместе с будущими анимациями гоблинов и лифта.
