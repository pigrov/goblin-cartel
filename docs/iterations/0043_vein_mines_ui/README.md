# Итерация 0043: UI жил и постоянных шахт

## Цель

Подключить core loop жил к клиенту: игрок видит особый блок жилы, получает событие при ее разрушении, переходит в меню шахт, строит постоянную шахту из найденной жилы и вручную собирает накопленный доход.

## Сделано

- В Pixi-отрисовку блоков добавлен отдельный визуальный слой для жил: медная жила выделяется прожилками и свечением.
- Render signature блоков теперь учитывает `special` и `veinTypeId`, чтобы Pixi корректно перерисовывал обычный блок и блок жилы.
- Добавлен клиентский state для построенных шахт внутри сохранения рудника.
- При разрушении жилы боссом, гоблином или офлайн-финальным ударом показывается модалка “Найдена жила”.
- Нижняя вкладка “Шахты” включена и показывает найденные жилы, стоимость строительства, построенные шахты, прогресс хранилища и кнопку ручного сбора.
- Построенные шахты производят ресурс в час, отображаются с учетом прошедшего времени и продолжают копить доход между входами.
- Добавлен `builtMineClientState` с unit-тестами для видимых шахт, доступности строительства и скрытия уже использованных жил.
