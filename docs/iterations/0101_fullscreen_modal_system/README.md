# Итерация 0101: общий полноэкранный компонент модалок

## Цель

Упаковать новый полноэкранный стиль попапов в переиспользуемый компонент и перевести на него ключевые игровые модалки без выноса новых настроек в админку.

## Сделано

- Добавлен `GameFullscreenModal` в `apps/game-client/src/ui/components`.
- Общий компонент отвечает за:
  - fullscreen-overlay поверх игрового экрана;
  - фон шахты;
  - верхнюю плашку с названием;
  - кнопку закрытия с PNG-крестиком;
  - фиксированную зону 240x240 под арт/аватар;
  - нижнюю информационную плашку со скроллом контента.
- На общий компонент переведены:
  - настройки;
  - подробная информация о гоблине;
  - параметры босса;
  - карты босса;
  - прогресс рудника;
  - подъемник;
  - вышка бригадира;
  - найденная жила;
  - завершение рудника.
- Для модалок рудника исправлен слой отображения: `GameFullscreenModal` монтируется через portal в `.phone-frame`, поэтому локальные окна рудника больше не остаются внутри `mine-screen-stage` и должны перекрывать resource bar, боковые кнопки и нижнее меню.
- Старые отдельные JSX-обертки с `modal-backdrop` и собственными шапками удалены из переведенных модалок.
- Старые CSS-дубли для fullscreen-структуры сведены к общим классам компонента; локальные классы теперь отвечают только за содержимое конкретной модалки.

## Важные решения

- Ассеты модалки пока остаются локальными файлами клиента, без загрузки через админку. Это сделано намеренно, чтобы сначала стабилизировать компонент и проверить стиль на нескольких сценариях.
- У общего компонента всегда есть зона под арт, даже если `avatarSrc` не передан. Это сохраняет одинаковую композицию между настройками, гоблином и будущими модалками.
- Для локальных модалок рудника используется portal в `.phone-frame`, а не обычный рендер внутри текущего экрана. Иначе `mine-screen-stage` создает отдельный stacking context и модалка может оказаться под шапкой ресурсов.
- Экран открытия сундука не переводился на этот компонент, потому что это отдельный игровой экран, а не обычная модалка.
- Модалка выбора сборщика в разделе постоянных шахт пока оставлена в старом стиле, так как она относится не к экрану рудника.
