# 0016 mine layout energy goblins

**Дата:** 2026-04-29
**Статус:** задеплоено

## Цель

Навести порядок на основном экране рудника после добавления энергии босса:

- убрать ресурс "Энергия босса" из верхней шапки ресурсов;
- дать игроку 600 стартовой энергии босса;
- сделать нижнюю игровую панель из двух равных блоков: энергия босса и гоблины;
- убрать строки под этими блоками с текущим камнем, гоблинами и количеством разбитых блоков;
- сделать контейнер игры полноэкранным в телефонном формате;
- ограничить скролл областью камней, чтобы весь экран игры не прокручивался.

## Входной контекст

- В `0015_boss_energy` энергия босса стала отдельной механикой и получила компактный блок.
- Верхняя шапка все еще выводит первые ресурсы из content bundle, включая `boss_energy`.
- Нижняя панель все еще содержит дополнительные строки: текущий блок, гоблины, награды/количество блоков.
- Контейнер телефона задан через `min-height`, поэтому при плотном контенте может прокручиваться вся страница.

## Решения

1. В шапке показывать только обычные ресурсы, исключая `boss_energy`.
2. Увеличить `maxEnergy` босса до 600, стартовое состояние остается полным.
3. Перестроить `boss-panel` в две колонки по 50%:
   - слева карточка энергии босса;
   - справа карточка гоблинов.
4. Карточка энергии продолжает открывать модалку параметров босса.
5. Карточка гоблинов показывает нанятых гоблинов, активных рабочих и суммарный DPS.
6. Убрать строки `active-block`, `reward-line` и нижний offline report из основной панели.
7. Задать фиксированную высоту телефонного контейнера через viewport и `minmax(0, 1fr)` для области камней.
8. Скролл разрешить только в `.mine-grid` и списке гоблинов.

## Сделано

- Верхняя шапка ресурсов теперь фильтрует `boss_energy`.
- Стартовая и максимальная энергия босса увеличена до 600.
- Нижняя панель рудника перестроена в две равные карточки:
  - слева энергия босса;
  - справа информация о гоблинах.
- Карточка энергии по-прежнему открывает модалку параметров босса.
- Карточка гоблинов показывает:
  - количество нанятых гоблинов;
  - количество активных рабочих;
  - суммарный урон в секунду.
- Клик по карточке гоблинов открывает раздел гоблинов.
- Убраны строки под карточками:
  - текущий блок и HP;
  - строка гоблинов;
  - количество разбитых блоков/последняя награда.
- Контейнер игры переведен на fixed viewport layout:
  - `html`, `body`, `#root` не прокручиваются;
  - `game-shell` занимает `100dvh`;
  - телефонный контейнер занимает весь экран телефона;
  - на десктопе остается ограниченная телефонная ширина.
- Скролл разрешен только в `.mine-grid` и в списке гоблинов.
