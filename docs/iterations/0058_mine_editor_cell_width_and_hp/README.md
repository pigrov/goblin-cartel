# 0058 Mine Editor Cell Width And HP

## Цель

Довести новый клеточный редактор рудника до более понятного поведения: сетка в админке должна визуально соответствовать ширине игровой пещеры, выбор материала должен быть быстрым через легенду, а прочность камней должна зависеть только от заданной сложности и параметров клетки.

## Сделано

- В админском paint-grid редакторе убран select выбора кисти.
- Легенда материалов стала набором кнопок: клик по материалу выбирает текущую кисть.
- Удален текст-подсказка под редактором.
- Ширина клеточной сетки в админке рассчитывается по формуле игровой Pixi-пещеры для телефонного viewport 430px: только сами клетки занимают ширину реальной шахты.
- Клиент больше не показывает Pixi-шахту до завершения загрузки опубликованного или fallback-контента, чтобы не было короткого показа другой карты.
- Runtime-контент автоматически обновляет старые опубликованные starter-рудники без `cellMap` до авторской карты клеток.
- Ключ локального сохранения рудника поднят до `mine-save.v2`, чтобы старые сохраненные блоки не восстанавливались поверх новой карты.
- Старый скрытый множитель глубины HP удален: при сложности `1 -> 1` блоки одного типа имеют одинаковую прочность на всех рядах.
