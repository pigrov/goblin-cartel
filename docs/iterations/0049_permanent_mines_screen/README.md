# Итерация 0049: полноценный экран постоянных шахт

## Цель

Развить вкладку `Шахты` в отдельный рабочий экран постоянной добычи: игрок должен видеть общий статус шахт, понимать какие шахты строятся, какие работают, какие заполнены, и быстро собирать накопленный доход.

## Сделано

- Экран `Шахты` получил сводку по постоянной добыче: количество работающих, строящихся и заполненных шахт.
- Добавлен общий сбор дохода со всех шахт, где уже накопился целый ресурс.
- Добавлен блок дохода в час по ресурсам, чтобы было видно, что дают построенные шахты.
- Найденные жилы вынесены в отдельную группу `Новые шахты`, а построенные шахты - в группу `Постоянные шахты`.
- Карточки шахт теперь явно показывают состояние `Строится`, `Работает` или `Заполнена`, прогресс стройки/хранилища, добычу в час и накопленный ресурс.
- Экраны `Гоблины` и `Шахты` опущены ниже прозрачной шапки ресурсов, чтобы верхний контент не перекрывался ресурсными блоками.
- Сводка шахт вынесена в клиентский state-helper и покрыта unit-тестом.
