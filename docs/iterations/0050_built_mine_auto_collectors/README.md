# Итерация 0050: автосбор постоянных шахт

## Цель

Добавить первую версию автоматизации постоянных шахт: нанятый гоблин-сборщик должен назначаться на шахту и автоматически переносить накопленный доход в ресурсы игрока, включая прогресс после возвращения в игру.

## Сделано

- В `game-core` добавлен расчет автоматического сбора для шахт с назначенным `assignedCollectorGoblinId`.
- Автосбор собирает только целые единицы ресурса, оставляя дробный остаток в хранилище шахты.
- Клиент раз в секунду обрабатывает шахты с назначенными сборщиками и обновляет ресурсы игрока.
- При восстановлении сохранения автоматизированные шахты сразу начисляют накопленный offline-доход.
- На карточку постоянной шахты добавлен блок `Автосбор` с назначением и снятием гоблина-сборщика.
- Экран найма теперь учитывает количество построенных шахт при проверке условий найма, поэтому гоблины с условием `built_mines_count` могут открываться.
- Из шапки экрана `Шахты` убран дублирующий счетчик `работают / строятся / заполнены`, чтобы экран не разъезжался на мобильной ширине.
- Добавлен unit-тест на автоматический сбор дохода назначенным сборщиком.

## Открытые вопросы

- Нужно решить, будет ли сборщик иметь отдельный экран назначения, когда появится больше постоянных шахт и несколько сборщиков.
