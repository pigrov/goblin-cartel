# 0013 visible goblin mining

**Дата:** 2026-04-29
**Статус:** реализовано локально

## Цель

Привести рудник ближе к ТЗ: гоблины должны быть видимыми рабочими на колонках рудника, бить только открытый верхний блок под собой, а удар босса не должен работать по закрытым нижним блокам.

## Входной контекст

- В `0012_goblin_auto_mining` гоблины уже добывают автоматически, но визуально они отображались как карточки бригады над рудником.
- По ТЗ игрок начинает с одним гоблином и докупает остальных.
- Гоблин может долбить только тот камень, который находится под ним.
- Boss hit должен работать только по открытым сверху камням, чтобы игрок не мог сразу выбрать нижний ценный блок.

## Решения

1. На руднике показывать только нанятых гоблинов.
2. Расставлять нанятых гоблинов по колонкам рудника.
3. Открытым считать первый неразбитый блок в каждой колонке.
4. Блоки ниже открытого верхнего блока делать недоступными для клика.
5. После разрушения активного блока переносить цель на следующий открытый блок по колонкам.
6. Сделать мини-гоблина CSS-иконкой с отбойным молотком и анимацией долбежки.

## Сделано

- На руднике сверху теперь показываются только нанятые гоблины.
- Стартовое состояние по-прежнему нанимает первого бесплатного гоблина, поэтому в начале на руднике виден один рабочий.
- Верхняя зона рудника стала сеткой из 8 колонок, синхронной с mine grid.
- Для нанятого гоблина добавлена мини CSS-иконка с головой, телом и отбойным молотком.
- Добавлена CSS-анимация долбежки.
- Добавлено понятие открытого блока: первый неразбитый блок в каждой колонке.
- Auto mining теперь расставляет нанятых гоблинов по открытым колонкам и наносит урон только блоку под конкретным гоблином.
- После разрушения активного блока цель переносится на следующий открытый блок по колонкам.
- Boss hit и клик по блоку теперь работают только по открытым сверху блокам.
- Закрытые нижние блоки затемняются и отключаются для клика.
