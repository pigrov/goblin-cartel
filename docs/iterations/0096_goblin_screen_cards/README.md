# Итерация 0096: карточки экрана гоблинов

## Цель

Начать переработку экрана гоблинов под новую концепцию индивидуальных случайных гоблинов: игрок должен быстрее отличать нанятых гоблинов по роли, редкости, уровню, имени, прозвищу и базовым статам.

## Сделано

- Пересобраны карточки нанятых гоблинов в компактный вид на 3 карточки в ряд.
- На карточке оставлены только ключевые данные:
  - уровень;
  - редкость;
  - имя и прозвище;
  - специализация;
  - сила, скорость и удача;
  - состояние кнопки улучшения.
- Модалка деталей гоблина стала крупнее и ближе к карточному игровому стилю:
  - большой портрет;
  - имя/прозвище;
  - роль, специализация и редкость;
  - текущий вклад и вклад после улучшения;
  - прогресс характеристик;
  - особенности и будущие слоты предметов.
- Новая графика не создавалась: UI использует только `assetId` рендера, загруженного через админку. Если ассет отсутствует или не загрузился, остается CSS fallback.

## Требования к рендерам гоблинов

- Формат: PNG или WebP.
- Фон: настоящая прозрачность alpha, без нарисованной шахматной подложки.
- Рекомендуемый размер: 1024x1024 или 1536x1536.
- Гоблин должен быть целиком в кадре, с запасом 5-8% по краям.
- Свет и контраст должны читаться на темно-синем/темно-коричневом UI.

## Проверки

- `pnpm --filter @goblin-cartel/game-client typecheck`
