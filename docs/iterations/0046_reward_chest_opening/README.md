# Итерация 0046: экран открытия наградного сундука

## Цель

Сделать награду за освоение рудника отдельным игровым событием: игрок получает сундук, тапает по нему на отдельном экране, видит вылет наград, итоговый список добычи и только после этого продолжает переход к следующему руднику.

## Сделано

- В content bundle добавлены `rewardChestTypes` с tier-типами `wooden`, `iron`, `steel`, `golden`, таблицей наград и ссылкой на ассет.
- В шаблон рудника добавлено поле `completionRewardChestTypeId`; первые два рудника теперь выдают деревянный и железный сундук.
- Валидация контента проверяет локализацию сундуков, ссылки на ресурсы в reward table и ссылки рудников на существующие сундуки.
- Backend content store сохраняет и восстанавливает `rewardChestType` как отдельную сущность версии контента.
- В `game-core` добавлена чистая функция `openRewardChest`, которая роллит награды по chance/min/max и объединяет одинаковые ресурсы.
- Клиент показывает полноэкранный экран сундука перед переходом в следующий рудник: сундук стоит снизу, по тапу открывается, награды вылетают вверх, затем показывается итог и кнопка “Продолжить”.
- Ручной переход к следующему руднику из меню шахт теперь сначала открывает сундук, если награда за текущий рудник еще не получена.
