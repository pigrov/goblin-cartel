# 0026 Damage Numbers Platform Drop

## Цель

Добавить понятную обратную связь по силе удара и поправить поведение платформы при спуске: числа урона должны быть видны над блоком, критический удар должен отличаться визуально, платформа должна быть чуть ниже, а игровой scroll не должен сам двигаться при спуске.

## Сделано

- Hit effect теперь хранит фактический `damage`.
- Над блоком рисуется плавающее число урона:
  - обычный удар босса показывает золотой урон;
  - удар гоблина показывает светлый урон;
  - критический удар показывает усиленный бейдж `КРИТ -N`.
- Анимация урона встроена в Pixi ticker: число появляется, поднимается вверх и плавно исчезает.
- Платформа опущена на 4px:
  - `platformGap` уменьшен с `6` до `2`;
  - добавлен unit-тест, который фиксирует новый зазор.
- Спуск платформы теперь плавный и без отскока:
  - убран sine-settle, который давал движение вниз-вверх-вниз;
  - оставлен простой smooth easing сверху вниз.
- Убран автоскролл при смене `currentPlatformRow`.

## Важные решения

- Число урона передается из игровой логики в Pixi вместе с hit effect. Это позволяет показывать реальные значения для босса, крита, гоблинов и офлайн-финального удара.
- Scroll остается под контролем игрока. Платформа может опускаться внутри шахты, но игровая область больше не вызывает `scrollTo` при этом событии.
- Критический удар выделен текстовым бейджем и светлой рамкой, без отдельной игровой механики.
