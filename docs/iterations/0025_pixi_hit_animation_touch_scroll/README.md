# 0025 Pixi Hit Animation Touch Scroll

## Цель

Улучшить ощущение удара по камню и поправить мобильное взаимодействие с шахтой: вертикальный свайп должен скроллить игровую область, платформа не должна залезать на камни, а гоблин должен визуально сидеть на платформе.

## Сделано

- Исправлена геометрия платформы:
  - платформа поднята примерно на 20px относительно блока;
  - добавлен явный `platformGap` между низом платформы и верхом блока;
  - гоблин опущен ниже внутри платформы, чтобы сидеть на ней, а не висеть над ней.
- Для Pixi canvas включен мобильный вертикальный жест:
  - `touch-action: pan-y` закреплен в CSS и инлайном после инициализации Pixi;
  - `autoPreventDefault` у Pixi event system отключен, чтобы обычный свайп не глушился canvas.
- Добавлен резервный ручной touch-pan для шахты:
  - вертикальный жест по области камней меняет `scrollTop` игрового контейнера;
  - случайный `pointertap` по блоку после свайпа кратко игнорируется, чтобы скролл не превращался в удар босса.
- Эффекты ударов переведены из статичного пятна в анимированную Pixi-композицию:
  - ударные кольца;
  - вспышка;
  - slash для босса и крита;
  - частицы пыли/искр/осколков;
  - усиленная анимация при разрушении блока.
- Добавлена короткая тряска целевого блока при ударе.
- Время жизни эффекта увеличено до 780ms, чтобы анимация успевала доиграть.
- Обновлены unit-тесты layout: теперь проверяется визуальный зазор между платформой и верхним рядом.

## Важные решения

- Свайп-скролл оставлен на уровне родительской игровой области. Если браузер все равно не отдает нативный scroll из-за canvas, включается ручной pan-scroll.
- Drag гоблина остается через Pixi pointer-события. Обычный свайп по шахте и тап по открытому блоку не должны конфликтовать.
- Платформа все еще рисуется отдельным слоем. Ее адресное обновление имеет смысл делать позже вместе с более сложными анимациями лифта и гоблинов.
