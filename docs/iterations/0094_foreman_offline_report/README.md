# Итерация 0094: отчет офлайн-работы бригадира

## Цель

Сделать возвращение в рудник понятнее: если бригадиры работали офлайн, игрок должен увидеть не только измененное состояние шахты, но и короткую сводку о перестановках, добитых блоках и полученной добыче.

## Сделано

- В офлайн-расчете рудника теперь считается количество реальных перестановок шахтеров бригадирами.
- Добавлен общий `OfflineMiningSummary` с полями времени, добитых блоков, перестановок, наград и признака финального удара.
- На экране рудника добавлена карточка "Бригадирская смена":
  - сколько гоблинов переставили;
  - сколько блоков добили;
  - сколько времени игрок был офлайн;
  - какие ресурсы получены;
  - заметка, если последний удар еще показывается в шахте.
- Сводку можно закрыть вручную, после чего она не мешает управлению рудником.
- Добавлен unit-тест на создание и форматирование офлайн-сводки.

## Проверки

- `pnpm --filter @goblin-cartel/game-client test -- offlineMiningSummary`

## Следующий шаг

Следующая полезная доработка экрана рудника: подсказки выгодности колонок. Для каждой колонки можно показывать, какой шахтер стоит сверху, какой у него урон по текущему блоку, есть ли бонус к типу ресурса и куда игроку выгоднее вручную переставить гоблина.
