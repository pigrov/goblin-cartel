# 0064 Content Driven Mine Upgrades

## Цель

Снять риск блокировки прогресса строительством шахт и вынести баланс улучшений постоянных шахт в контент, чтобы менять стоимость, максимальный уровень и множители через админку без релиза кода.

## Решения

- Переход в следующий рудник доступен сразу после полной расчистки текущего рудника, то есть после появления жилы.
- Постоянная шахта больше не является обязательным условием перехода. Она остается отдельным источником дохода и точкой долгосрочного прогресса.
- Баланс улучшений добавлен в `builtMineTypes.upgrade`:
  - `maxLevel`;
  - `productionMultiplier`;
  - `capacityMultiplier`;
  - строки стоимости с конкретным ресурсом или ресурсом добычи самой шахты.
- Стоимость апгрейда считается как `baseAmount * (level * levelMultiplier) ^ levelPower`.
- В админке форма типа шахты получила редактирование параметров улучшения и строк стоимости.

## Контент

- Стартовый набор рудников расширен до пяти 10-метровых рудников.
- Сложность рудников выставлена мягкой ступенькой:
  - `old_well_01`: 1 -> 1.15;
  - `abandoned_crosscut_02`: 1.05 -> 1.2;
  - `lower_gallery_03`: 1.1 -> 1.25;
  - `sunken_works_04`: 1.15 -> 1.3;
  - `red_iron_drop_05`: 1.2 -> 1.35.

## Проверки

- Unit-тесты обновлены для content-driven апгрейдов и перехода после расчистки рудника.
- Обязательный `encoding:check` остается частью локальных и CI/CD проверок.

## Открытые вопросы

- Нужно решить, какие значения апгрейдов публиковать как первую боевую версию баланса после ручного теста.
- Следующий шаг по механике: сделать экран подробностей шахты и вынести апгрейд в отдельное действие с подтверждением.
