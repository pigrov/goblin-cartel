# Итерация 0100: ресурсные иконки и прозрачная шапка

## Цель

Перенести ресурсные и системные иконки в управляемый через админку content, подключить новые визуальные ассеты шапки ресурсов и кнопки настроек, а саму шапку оставить полностью прозрачной поверх игрового поля.

## Сделано

- Добавлена новая content-сущность `uiIcons`:
  - `resources` хранит asset ID иконок ресурсов;
  - `stats` хранит asset ID иконок характеристик гоблина;
  - `controls` хранит asset ID системных кнопок, сейчас это подложка кнопки настроек и иконка шестеренки.
- В админке раздел `Content -> Иконки` теперь управляет:
  - иконками ресурсов;
  - иконками характеристик гоблина;
  - иконками интерфейса.
- Иконки силы, скорости, удачи и лояльности перенесены из настроек генерации в общий раздел `Иконки`.
- Плашки цены normal/disabled удалены из обычного UI генерации, так как больше не используются в текущем дизайне.
- В starter/default assets добавлены:
  - `icon_gold_v1`;
  - `icon_stone_v1`;
  - `icon_iron_v1`;
  - `ui_resource_chip_frame_v1`;
  - `ui_settings_button_frame_v1`;
  - `ui_settings_gear_v1`.
- Верхний resource bar теперь использует:
  - отдельную настраиваемую подложку ресурса;
  - asset-иконки золота, камня и железа;
  - отдельную asset-подложку и шестеренку для кнопки настроек.
- Эликсир убран из верхней шапки и показывается в кнопке карт/босса в левой колонке рудника.
- Медь убрана из верхней шапки и показывается в кнопке бомбы/умения в левой колонке рудника.
- У `.resource-bar` убраны общий `background`, `backdrop-filter` и `-webkit-backdrop-filter`, чтобы игровой контент был виден под шапкой без затемнения и размытия.

## Важные решения

- Для подложки ресурса и кнопки настроек пока используется цельная PNG-картинка без 9-slice. Если на маленьких ширинах будет заметна деформация углов или рамки, следующий шаг - перевести эти элементы на 9-slice.
- `uiIcons` сделан отдельной content-сущностью, а не частью `goblinGeneration`, потому что иконки используются не только экраном гоблинов.
- В клиенте оставлены безопасные fallback asset ID для старого опубликованного контента до перепубликации версии.
