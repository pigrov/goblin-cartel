# 0015 boss energy

**Дата:** 2026-04-29
**Статус:** в работе

## Цель

Навести порядок с энергией босса:

- удар босса должен расходовать энергию;
- энергия должна постепенно восстанавливаться;
- кнопка "Удар босса" больше не нужна, потому что основной удар уже выполняется тапом по открытому камню;
- игрок должен видеть компактный блок энергии босса;
- по клику на блок энергии должна открываться модалка с параметрами босса.

## Входной контекст

- В текущем клиенте урон босса задан константой `bossBaseDamage`, а отдельного состояния энергии нет.
- Удар по камню уже ограничен открытыми сверху блоками.
- На экране есть отдельная кнопка `Удар босса`, которая дублирует тап по камню и визуально путает механику.
- Проект ведет документацию итераций и обязательные проверки: unit tests, typecheck, lint, UTF-8/mojibake, Drizzle check, build.

## Решения

1. Добавить в `@goblin-cartel/game-core` чистую механику энергии босса:
   - текущее значение энергии;
   - максимум энергии;
   - расход на удар;
   - восстановление в секунду;
   - урон за тап;
   - шанс крита;
   - множитель крита.
2. Хранить в save состояние энергии босса и время последнего обновления.
3. Восстанавливать энергию по прошедшему времени при загрузке и на экране.
4. При тапе по открытому камню сначала пытаться потратить энергию.
5. Если энергии не хватает, урон не проходит, а energy block получает короткий feedback.
6. Убрать кнопку "Удар босса".
7. Добавить компактный блок энергии и модалку параметров босса.
8. Добавить unit-тесты на восстановление энергии, успешный удар, отказ при нехватке энергии и крит.

## Сделано

- Добавлен `boss-energy` модуль в `@goblin-cartel/game-core`.
- Добавлены unit-тесты на:
  - создание полной энергии;
  - восстановление энергии по времени;
  - расход энергии при успешном ударе;
  - отказ при нехватке энергии и расчет времени ожидания;
  - критический удар;
  - восстановление сохраненной энергии при загрузке.
- Клиент хранит `bossEnergy` в локальном mine save.
- При загрузке сохранения энергия восстанавливается с учетом времени.
- Удар по открытому камню теперь сначала тратит энергию босса.
- Если энергии не хватает, урон не проходит, а energy block получает визуальный feedback.
- Критический удар наносит увеличенный урон и получает отдельный эффект.
- Кнопка "Удар босса" убрана.
- Добавлен компактный блок энергии босса:
  - текущее/максимальное значение;
  - вертикальная заливка остатка энергии;
  - урон за тап;
  - скорость восстановления.
- По клику на блок энергии открывается модалка параметров босса.
