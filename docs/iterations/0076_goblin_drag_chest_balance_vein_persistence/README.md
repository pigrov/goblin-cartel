# Итерация 0076: Goblin drag, chest balance, vein persistence

## Цель

- Нормализовать область хватания гоблина в Pixi до размера клетки шахты и сделать ее временно видимой для проверки.
- Перенести баланс карт босса/эликсира в админку сундуков, чтобы менять шансы без правки кода.
- Не терять найденную жилу, если игрок ушел в новый рудник до строительства шахты.

## Решения

- Гоблин при перетаскивании скрывается на платформе, а drag-preview слегка увеличивается.
- Балансер сундука в админке управляет эликсиром и картами по редкости поверх обычной `rewardTable`, без новой схемы рантайма.
- При переходе в новый рудник найденные, но еще не построенные жилы переносятся в новую mining session.
- В экране шахт убран блок текущего рудника; после зачистки показывается отдельная кнопка `Новый рудник`.

## Сделано

- Добавлен тест размера Pixi grab-area.
- Добавлен helper и тест применения chest/card balance в админке.
- Добавлен helper и тест переноса найденных жил между рудниками.
