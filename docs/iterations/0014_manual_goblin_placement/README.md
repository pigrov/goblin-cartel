# 0014 manual goblin placement

**Дата:** 2026-04-29
**Статус:** задеплоено

## Цель

Уточнить механику гоблинов на руднике:

- гоблин видим как рабочий над колонкой и сидит на отбойном молотке;
- гоблин не выбирает соседний камень сам;
- перенос гоблина выполняется вручную через захват и сброс на открытую клетку;
- гоблин работает только по открытому камню в своей колонке;
- удар босса по открытому камню дает заметный визуальный эффект.

## Входной контекст

- В `0013_visible_goblin_mining` гоблины уже стали видимыми и били только открытые сверху блоки.
- В предыдущей реализации гоблины автоматически распределялись по открытым колонкам и после разрушения активной цели могли перескакивать к следующей.
- По ТЗ автоперенос на другой камень должен быть отдельной будущей механикой: умение гоблина, управляющий гоблин или другая автоматизация.
- Офлайн-прогресс должен сохранять ощущение работы гоблинов: после возвращения игрок видит результат и финальный удар по удержанному блоку.

## Решения

1. Хранить ручные позиции гоблинов отдельно от выбранного блока босса.
2. Позиция гоблина сейчас задается колонкой рудника: визуально гоблин стоит над колонкой и долбит верхний открытый блок под собой.
3. Не переносить гоблина в соседнюю колонку после разрушения блока.
4. Если игрок переносит гоблина на занятую колонку, гоблины меняются колонками, чтобы ни один не оказался "в воздухе".
5. Офлайн-добычу считать по колонкам, на которых стоят гоблины, а не по глобальному следующему блоку шахты.
6. Для офлайн-добычи добавить unit-тесты на добычу строго внутри выбранной колонки и удержание финального блока на 1 HP.
7. Удар босса и удар гоблина получают короткие визуальные эффекты на блоке.

## Сделано

- Добавлен `applyColumnAutoMining` в `@goblin-cartel/game-core`.
- Добавлены unit-тесты для column auto mining:
  - добыча не выходит за выбранную колонку;
  - офлайн-удержание последнего разрушения оставляет блок на 1 HP.
- В клиенте добавлен `goblinPlacements` и сохранение позиций в localStorage save.
- Восстановление игры поднимает позиции гоблинов из save или расставляет стартовую бригаду по открытым колонкам.
- Нанятый гоблин получает первую свободную открытую колонку.
- Перенос гоблина работает через pointer drag/drop и HTML drag/drop.
- Drop разрешен только на открытые сверху неразбитые блоки.
- Auto mining использует только сохраненные позиции гоблинов.
- Offline mining использует только колонки, на которых стоят гоблины.
- Иконка гоблина переделана: гоблин сидит над вертикальным отбойным молотком.
- Для удара босса добавлены искры, вспышка и встряска блока.
- Для удара гоблина добавлен короткий эффект пыли/скола.
