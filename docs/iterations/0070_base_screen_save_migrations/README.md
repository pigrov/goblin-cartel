# 0070 Base Screen Save Migrations

## Цель

Разделить развитие инфраструктуры и управление гоблинами, чтобы Хижина стала частью общей Базы, а экран гоблинов остался про найм, роли и прокачку. Параллельно убрать риск сброса прогресса при публикации новой версии контента.

## Сделано

- В нижнюю навигацию добавлен отдельный раздел `База`.
- Карточка улучшения Хижины перенесена из экрана гоблинов в экран Базы.
- Экран гоблинов оставлен под карточки гоблинов, вкладки ролей, найм и индивидуальные улучшения.
- В Базе заложены компактные будущие слоты инфраструктуры: склад, подъемник, знания.
- Добавлен общий ключ локального сохранения `goblin-cartel.player.save.v1`.
- Старые ключи `mine-save.v2` и `goblin-roster.v1` автоматически мигрируют в общий save, но пока остаются записанными для совместимости.
- Восстановление шахты и ростера больше не отбрасывает сохранение только из-за смены `contentVersion`.
- Если активный шаблон рудника исчезнет из контента, клиент сохраняет ресурсы, постоянные шахты и отметки прохождения вместо полного обнуления.
- Добавлены unit-тесты на запись общего сохранения, миграцию legacy-ключей и сохранение прогресса при смене версии контента.
