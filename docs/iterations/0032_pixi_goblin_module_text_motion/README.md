# 0032 Pixi Goblin Module Text Motion

## Цель

Продолжить дробление Pixi-сцены по зонам ответственности и поправить мелкие UX-проблемы в шахте.

## Сделано

- Вынесена отрисовка гоблина из `MinePixiScene.tsx` в `minePixiGoblins.ts`.
- Добавлена расширенная область захвата гоблина, чтобы drag начинался без точного попадания в маленькую иконку.
- Добавлен unit-тест на размеры goblin grab hit area.
- Убран flash-фон у текста критического удара: крит теперь отображается только текстом с тенью.
- Подъем текстов урона и наград в hit effect увеличен в два раза.

## Проверки

- `pnpm --filter @goblin-cartel/game-client typecheck`
- `pnpm --filter @goblin-cartel/game-client test`
- Визуальная проверка Pixi canvas:
  - drag гоблина из расширенной зоны слева от иконки сохраняет размещение в новой колонке;
  - критический удар показывает только текст без подложки;
  - текст урона поднимается выше прежнего.
