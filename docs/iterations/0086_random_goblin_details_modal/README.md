# 0086 Random Goblin Details Modal

## Цель

Сделать случайного гоблина понятной единицей вложения: игрок должен открыть конкретного гоблина и увидеть, что именно прокачивает.

## Сделано

- Карточка личного гоблина в Хижине теперь открывает модалку деталей.
- В модалке показываются имя, редкость, роль, описание, текущий уровень и прогноз урона после следующего уровня.
- Статы показывают текущие значения и прирост на следующем уровне.
- Показываются особенности rolled-гоблина.
- Добавлен блок будущих предметных слотов по архетипу контракта: инструмент, книга, свисток и fallback для новых слотов.
- Кнопка улучшения на карточке не открывает модалку, а сразу прокачивает выбранный экземпляр.
