# Итерация 0048: карточки строительства шахт

## Цель

Сделать меню шахт понятнее после нахождения жилы: игрок должен видеть, какую шахту можно построить, сколько ресурсов не хватает, сколько займет строительство, как идет таймер стройки и сколько ресурсов уже накопила построенная шахта.

## Сделано

- В меню `Шахты` карточка найденной жилы теперь показывает проект шахты, добычу в час, стоимость строительства по ресурсам и недостающие ресурсы.
- Карточки построенных шахт разделяют состояние строительства и активной добычи: во время строительства показывается прогресс и оставшееся время, после запуска - заполнение хранилища.
- Для заполненного хранилища добавлен отдельный статус, чтобы игрок понимал, что шахта простаивает до сбора.
- Логика клиентского отображения стоимости, прогресса строительства и заполнения хранилища вынесена в `builtMineClientState`.
- Добавлены unit-тесты на расчет требований строительства, прогресса стройки и заполнения хранилища.
