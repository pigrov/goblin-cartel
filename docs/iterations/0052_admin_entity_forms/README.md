# Итерация 0052: entity-формы контента в админке

## Цель

Перевести редактирование ключевых игровых сущностей из ручной правки JSON в нормальные формы админки, сохранив текущий безопасный flow `draft JSON -> Save -> Validate -> Publish`.

## Сделано

- На экране `Content` добавлен entity-редактор с вкладками `Гоблины`, `Рудники`, `Типы шахт`.
- Добавлен список сущностей с выбором конкретной записи и форма редактирования справа.
- ID пока оставлен read-only, чтобы не ломать связи между сущностями и сохранениями.
- Для гоблина редактируются RU-тексты, класс, специализация, редкость, asset ID, базовые статы, умение, слоты автосбора, бонусы шахт и первая стоимость найма.
- Для рудника редактируются RU-название, sort order, размер, глубина, сложность, seed mode, жила после расчистки и сундук перехода.
- Для типа постоянной шахты редактируются RU-название, asset ID, исходная жила, ресурс добычи, добыча в час, вместимость, время стройки и две строки стоимости.
- Перед применением формы в draft JSON выполняется локальная валидация: обязательные поля, типы чисел, диапазоны, ссылки на ресурсы/жилы/сундуки.
- Кнопка `Применить в JSON` активна только когда локальная форма валидна; после применения остаются штатные `Save`, `Validate`, `Publish`.
