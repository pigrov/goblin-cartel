# Итерация 0098: asset skin карточек найма

## Цель

Подключить production pack ассетов для карточек найма гоблинов так, чтобы картинки не были захардкожены в клиенте и могли заменяться через админку.

## Сделано

- Добавлен `hireCardSkin` в `goblinGeneration` content:
  - подложки карточек по редкости;
  - состояния кнопки найма;
  - плашки цены;
  - иконки цены и характеристик.
- В админке раздел `Content -> Генерация` получил блок `UI карточки найма`.
- Каждый слот скина можно заполнить Asset ID или загрузить PNG/WebP/JPG через админку.
- Backend получил общий endpoint `/admin/assets`; старый `/admin/assets/goblin-renders` сохранен для совместимости.
- Добавлен seed default assets:
  - файлы лежат в `apps/backend/assets/default`;
  - при старте backend копирует отсутствующие файлы в `APP_ASSET_STORAGE_DIR`;
  - уже загруженные пользователем файлы не перезаписываются.
- Карточки найма в клиенте используют assetId из `hireCardSkin` через `/api/assets`, а не прямые пути к файлам.

## Как использовать pack

1. Создать или открыть draft content version.
2. Перейти в `Content -> Генерация`.
3. В блоке `UI карточки найма` проверить дефолтные Asset ID или заменить нужные файлы загрузкой.
4. Сохранить draft, проверить и опубликовать версию.

## Важные решения

- Full-card PNG используется как skin/background, но текст, цена, статы и доступность кнопки остаются живыми данными игры.
- Role renders из pack добавлены как seed assets, но не навязаны всем архетипам автоматически. Их можно добавить в render pool через админку.
- Для текущих опубликованных версий без `hireCardSkin` клиент использует дефолтные assetId, чтобы экран не ломался до перепубликации контента.
