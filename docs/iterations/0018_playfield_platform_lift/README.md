# 0018 Playfield Platform Lift

## Цель

Уточнить визуальную модель платформы после первой реализации:

- платформа не должна быть шире каменной сетки, потому что слева у шахты есть колонка глубины;
- скролл должен быть единым для поверхности и шахты;
- платформа с гоблинами должна визуально находиться внутри шахты на текущей глубине;
- слева на поверхности нужен механизм спуска, который реагирует на опускание платформы.

## Сделано

- Поверхность и шахта перенесены в общий контейнер `playfield-scroll`.
- Скролл теперь общий для леса/поверхности и шахты, а не только для `.mine-grid`.
- Платформа вынесена из поверхности в отдельную строку `mine-platform-row` внутри шахты.
- `mine-platform-row` использует ту же сетку `34px + N колонок`, что и ряды камней, поэтому платформа совпадает по ширине с пещерой.
- Слева на поверхности добавлен CSS-механизм спуска: колесо, стойка и трос.
- В левой колонке шахты добавлен визуальный трос платформы.
- При увеличении `platformRow` включается короткая анимация колеса/троса и опускания платформы.
- На стартовом ряду автоскролл оставляет поверхность видимой; на глубине скролл подводит текущую платформу в область просмотра.
