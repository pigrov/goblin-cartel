# 0017 Surface Platform Mining

## Цель

Перевести механику гоблинов с автоперехода по колонке на платформу:

- поверхность занимает отдельную фиксированную зону над шахтой;
- гоблины стоят на платформе и бьют только камень текущего ряда под собой;
- платформа опускается ниже только после очистки всего ряда;
- босс сохраняет прежнее правило и может бить любой открытый сверху блок, независимо от платформы;
- большая шахта скроллится только в области камней, с метками глубины слева.

## Сделано

- В `@goblin-cartel/game-core` добавлен `applyPlatformAutoMining`.
- Добавлены `findPlatformRow` и `isMineRowCleared`.
- Offline mining для гоблинов переведен на платформенную модель.
- В localStorage save добавлен `platformRow`.
- Гоблины теперь не выбирают следующий камень сами: если камень под гоблином разбит, он остается в своей колонке и ждет ручной перестановки или опускания платформы.
- Дроп гоблина разрешен только на неразбитые блоки текущего ряда платформы.
- Босс продолжает работать через `findExposedCells`: можно бить верхний открытый блок в любой колонке.
- На клиенте добавлена зона поверхности с лесом/полянкой, шахтным входом, платформой и текущей глубиной.
- Сетка шахты рендерит все ряды, а не первые 56 блоков.
- Метки глубины выводятся слева от рядов шахты.
- Автоскролл подводит текущий ряд платформы в видимую область шахты.

## Открытые вопросы

- Offline mining сейчас симулируется последовательно по гоблинам. Для MVP этого достаточно, но позже стоит заменить на более точную time-slice симуляцию, чтобы несколько гоблинов работали полностью синхронно во время отсутствия игрока.
- Визуал поверхности пока CSS-based. Позже можно заменить лес/платформу на полноценные игровые ассеты.
