# Итерация 0097: контракты и reveal гоблинов

## Цель

Продолжить переработку экрана гоблинов: карточки найма и окно получения нового гоблина должны работать в том же стиле, что и карточки нанятых гоблинов.

## Сделано

- Карточки контрактов найма перестроены под карточный UI.
- До найма игрок видит:
  - роль контракта;
  - специализацию;
  - стоимость;
  - диапазон силы, скорости и удачи;
  - шансы редкости.
- Reveal нового гоблина стал крупнее:
  - большой портрет из загруженного через админку рендера;
  - отдельный бейдж редкости;
  - роль и специализация;
  - стартовые характеристики;
  - особенности;
  - будущие слоты предметов.
- Удалены старые стили reveal-карточки, которые больше не используются.

## Ограничения по ассетам

Новая графика не создавалась. Все портреты по-прежнему берутся из `assetId`, выбранного генерацией гоблина из render pool, который настраивается через админку.
