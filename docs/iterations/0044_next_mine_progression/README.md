# Итерация 0044: переход к следующему руднику

## Цель

Добавить первый слой прогрессии после освоения жилы: игрок строит постоянную шахту из найденной жилы текущего рудника и получает возможность перейти к следующему руднику, сохранив ресурсы и построенные шахты.

## Сделано

- В стартовый контент добавлен второй рудник `abandoned_crosscut_02` с локализацией “Заброшенный штрек”.
- Создание `MiningSession` теперь умеет стартовать конкретный `mineTemplateId` и переносить текущие ресурсы игрока.
- Восстановление сохранения теперь выбирает рудник из сохраненного `mineTemplateId`, а не всегда первый шаблон.
- В меню “Шахты” добавлена карточка текущего рудника и кнопка перехода к следующему.
- Переход к следующему руднику разрешается только если из жилы текущего рудника уже построена постоянная шахта.
- Добавлен модуль `mineProgressionClientState` с unit-тестами для определения следующего рудника и проверки условия перехода.
