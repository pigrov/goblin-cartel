# 0055 Admin Content Routes Templates

## Цель

Сделать раздел Content удобнее для роста контента: вынести выбор/создание версии на отдельный экран `/admin/content`, а редактирование конкретной версии открывать по прямому адресу `/admin/content/<version>`. Добавить шаблоны создания новых блоков и сундуков, чтобы вкладки сущностей работали не только с уже существующими объектами.

## Сделано

- Раздел Content теперь поддерживает навигацию через адресную строку: `/admin/content` показывает создание и список версий, `/admin/content/0.0.5` открывает редактор конкретной версии.
- При выборе или создании версии админка обновляет URL без перезагрузки страницы, а прямое открытие версии подгружает нужный draft по `version` или `id`.
- Старый список версий убран из редактора, чтобы форма сущностей и JSON-режим занимали всю ширину.
- Экран `/admin/content` получил компактную форму создания draft и карточки существующих версий.
- В инструменты draft добавлены шаблоны `Блок` и `Сундук`.
- После создания шаблона редактор автоматически переключается на нужную вкладку и выбирает созданную сущность.
- Для admin-пакета добавлен `test` script и unit-тесты на маршруты Content, шаблон блока и шаблон сундука.

- Ручной JSON-редактор пока остается на экране версии как advanced mode.
