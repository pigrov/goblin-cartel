# 0063 Mine Progression Upgrades

## Цель

Закрепить основной цикл рудника: игрок расчищает рудник, находит жилу, строит постоянную шахту, дожидается ее запуска, получает доход и только после этого переходит в следующий рудник.

## Решения

- Переход в следующий рудник теперь требует активную постоянную шахту из текущей жилы, а не просто начатое строительство.
- Для экрана шахт добавлен явный статус прогресса текущего рудника: копаем, жила найдена, шахта строится, следующий рудник открыт.
- В ядро добавлена базовая механика улучшения постоянной шахты до 5 уровня.
- Стоимость улучшения считается из текущей добычи шахты: ресурс самой шахты плюс золото. Если шахта добывает золото, стоимость схлопывается в одну золотую позицию.
- Улучшение сразу повышает добычу в час и вместимость хранилища, но недоступно до завершения строительства.

## Сделано

- Добавлены `calculateBuiltMineUpgradeCost`, `calculateBuiltMineUpgradeStats` и `upgradeBuiltMine` в `@goblin-cartel/game-core`.
- Добавлен `createBuiltMineUpgradePreview` в клиентский слой состояния шахт.
- Обновлен экран постоянных шахт: карточки показывают следующий уровень, прирост добычи/вместимости, стоимость и кнопку улучшения.
- Обновлена прогрессия рудников: `canMoveToNextMine` требует активную шахту.
- Добавлены unit-тесты на core-апгрейд, UI-preview апгрейда и статусы прогрессии.
