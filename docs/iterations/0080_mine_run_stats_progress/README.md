# 0080 mine run stats progress

## Цель

Добавить понятную статистику прохождения рудника: игрок должен видеть, что он получил за полный рудник, и иметь быстрый доступ к текущему прогрессу до завершения.

## Входной контекст

- В итерации `0079_mine_depth_rewards_deploy` появилась content-driven награда за метры спуска платформы.
- В руднике уже есть отдельные события: добыча с камней, бонус за глубину, сундук перехода и найденная жила.
- Пользователю нужен более читаемый прогресс рудника без нового крупного блока, который перекроет игровую область.

## Решения

- Статистика прохождения вынесена в маленький UI-модуль `mineRunStats`, а не оставлена внутри большого контроллера.
- Статистика хранит отдельно:
  - разрушенные камни;
  - ресурсы, полученные из камней;
  - ресурсы, полученные за глубину.
- Состояние статистики сохраняется в player save вместе с рудником.
- Офлайн-добыча добавляется в статистику при восстановлении сохранения.
- При переходе в новый рудник или полном сбросе статистика создается заново для нового `mineTemplateId`.
- В руднике добавлена компактная кнопка прогресса, чтобы не занимать постоянное место на экране.

## Сделано

- Добавлен модуль `mineRunStats` с восстановлением старых сохранений, суммированием наград и view-model для итогов/текущего прогресса.
- Добавлены unit-тесты на:
  - раздельный учет наград камней и глубины;
  - сброс статистики при смене рудника;
  - восстановление сохранения;
  - формирование итогов и текущего прогресса.
- Модалка завершения рудника теперь показывает:
  - сколько камней разрушено;
  - глубину рудника;
  - итоговую добычу;
  - разбивку добычи по камням и глубине.
- В экране рудника появилась кнопка прогресса с процентом очистки и текущей глубиной.
- По кнопке открывается модалка прогресса с:
  - процентом очистки;
  - текущей/полной глубиной;
  - количеством разрушенных камней;
  - жилой, которая будет найдена после полной расчистки;
  - правилом бонуса за глубину;
  - уже полученными ресурсами.
