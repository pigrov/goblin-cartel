# 0056 Admin Mine Visual Editor Goblin Grab

## Цель

Добавить в админку первый визуальный редактор рудника, чтобы структуру шахты можно было править не только через поля и JSON. Дополнительно увеличить область хватания гоблина в игровой шахте, чтобы на телефоне было меньше промахов при перетаскивании.

## Сделано

- В форме `Рудники` появился блок `Визуальный редактор шахты`.
- Редактор показывает строки шахты, цвет доминирующего блока по текущим весам `strata`, маркеры жил и сундуков.
- Добавлены быстрые действия: выставить начало слоя, выставить конец слоя, поставить объект на выбранный ряд.
- Добавлена кнопка равномерного раскладывания strata по всей высоте рудника.
- Добавление объекта из визуального редактора создает стартовую жилу на выбранном ряду и сразу переводит действие клика в режим объекта.
- Область хватания Pixi-гоблина увеличена с прежних 46x84 до минимум 68x116 визуальных пикселей.
- Unit-тесты покрывают helpers визуального редактора рудника и новый размер hit area гоблина.

## Открытые вопросы

- Текущий визуальный редактор редактирует структуру генерации рудника, а не фиксированную клеточную карту. Это соответствует текущей модели `strata + guaranteedObjects`.
- Следующий шаг: добавить более продвинутый режим предпросмотра с seed, чтобы админ видел конкретно сгенерированную карту блоков перед публикацией.
