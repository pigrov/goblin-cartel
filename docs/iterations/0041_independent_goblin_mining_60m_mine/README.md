# Итерация 0041: независимая добыча гоблинов и шахта 60м

## Цель

Исправить баг, при котором частые удары босса могли сбивать авто-добычу гоблинов, и вернуть текущую тестовую шахту к глубине 60 метров.

## Сделано

- Авто-добыча гоблинов переведена на стабильный `setInterval`, который не пересоздается при boss tap, смене `activeCell` или движении платформы.
- Актуальные данные для авто-добычи теперь читаются из refs: выбранная клетка, блоки контента, расстановка гоблинов, список нанятых гоблинов, pending offline final hit и текущая строка платформы.
- Стартовая шахта в `starterContentBundle` изменена на `12` рядов и `60` метров.
- Runtime-оверрайд опубликованного старого контента теперь нормализует первую шахту к `12` рядам и `60` метрам, а strata пересчитываются по всей глубине.
- `contentVersionWithRuntimeSuffix` теперь меняет suffix для 60м-шахты, чтобы старые локальные сохранения от 200м-шахты не восстановились поверх нового размера.
- Обновлены unit-тесты `runtimeContent`.

## Идеи для полного очищения шахты

- Состояние `mine_complete`: когда все блоки разрушены, блокируем добычу, показываем итоговую сводку по глубине, ресурсам и времени.
- Кнопка "Спуститься глубже": генерирует следующую шахту с новым seed, увеличенной сложностью и новой глубиной/слоями.
- Награда за зачистку: отдельный chest/relic/upgrade currency, который нельзя получить обычными блоками.
- Выбор маршрута: после зачистки игрок выбирает один из 2-3 вариантов следующей шахты, например "много меди", "больше сундуков", "опасные плотные породы".
- Возврат на поверхность: короткий экран с платформой, которая поднимает добычу наверх, и затем старт новой шахты.
