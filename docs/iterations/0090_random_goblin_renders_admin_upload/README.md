# 0090 random goblin renders admin upload

## Цель

Подготовить ветку случайных гоблинов к нормальным арт-рендерам: админка должна уметь загружать портреты по `assetId`, backend должен хранить и публично отдавать эти файлы, а клиент должен показывать рендер в карточках гоблинов с fallback на процедурный портрет.

## Сделано

- Добавлен backend-роут `POST /admin/assets/goblin-renders` для загрузки `PNG/WebP/JPG` до 5 MB.
- Добавлена публичная выдача ассетов через `GET /assets/:assetId`; снаружи это доступно как `/api/assets/:assetId`.
- В production compose добавлен постоянный Docker volume `asset_data` и `APP_ASSET_STORAGE_DIR=/app/storage/assets`.
- В админке у сущности `goblin` появился блок загрузки рендера рядом с `Asset ID`: preview, автозаполнение id из имени файла, загрузка в текущую админ-сессию.
- Клиентские карточки и модалки гоблинов теперь берут изображение по `assetId`; если ассет не найден или не загрузился, остается старый CSS-портрет.
- В документацию добавлен формат рендера для загрузки в админку.

## Формат рендеров

- Предпочтительно `PNG` или `WebP` с прозрачным фоном; `JPG` допустим только временно.
- Размер файла до 5 MB.
- Рабочий исходник: квадрат `1024x1024`, минимум `512x512`.
- Без текста, UI-рамки и цветного фона.
- Персонаж должен читаться на маленькой карточке: крупная голова, ясный силуэт, роль/инструмент заметны.
- Безопасные поля 8-12% от края.
- `assetId`: латиница, цифры, `_`, `-`, `.`, например `goblin_miner_common_01`.
